PROJECT BRIEF
Aplikasi Collaborative Habit Tracker Real-Time Berbasis Laravel

1. DESKRIPSI PROJECT
Membuat aplikasi web yang memungkinkan beberapa pengguna untuk membuat dan mengelola daftar habit (kebiasaan) secara bersama-sama dalam satu board. Semua perubahan akan langsung terlihat oleh seluruh anggota board secara real-time.

Contoh:
- Budi membuat board "30 Days Coding Challenge"
- Budi mengundang Lisa
- Budi menambahkan habit "Belajar Laravel 1 Jam"
- Lisa menambahkan habit "Push ke GitHub"
- Keduanya dapat checklist habit setiap hari
- Semua perubahan langsung tersinkronisasi

2. TUJUAN PROJECT
- Membuat aplikasi habit tracker yang dapat digunakan bersama-sama.
- Mendukung kolaborasi real-time antar pengguna.
- Menampilkan siapa yang sedang mengedit data.
- Menyimpan riwayat revisi board.
- Menangani konflik saat beberapa user mengedit bersamaan.

3. TEKNOLOGI YANG DIGUNAKAN
- Laravel 12
- Laravel Reverb (WebSocket)
- Laravel Breeze (Authentication)
- MySQL
- JavaScript / Alpine.js
- Tailwind CSS atau Bootstrap

4. FITUR WAJIB SESUAI KETENTUAN DOSEN

A. Multi-User Editing (Same Document)
- Beberapa user dapat membuka board yang sama.
- User dapat add/edit/delete habit.
- User dapat check/uncheck habit.
- Semua perubahan langsung terlihat oleh user lain.

B. Live Cursor Tracking
- Menampilkan user yang sedang mengedit habit tertentu.
- Contoh: "Budi sedang mengedit habit Belajar Laravel."

C. Version Tracking (Document Revision)
- Menyimpan riwayat perubahan board.
- Menyimpan informasi:
  - user yang melakukan perubahan
  - waktu perubahan
  - jenis perubahan (add/edit/delete/check)

D. Conflict Resolution
- Jika dua user mengedit secara bersamaan, sistem memproses perubahan berdasarkan timestamp.
- Semua perubahan tetap tersimpan.
- Data semua user tetap sinkron.
